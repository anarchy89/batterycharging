batterycharging

Stop your MacBook from charging while it is plugged in, on macOS 27 and 26.7 or later.

batterycharging holds the battery where it is, charges it to a level you pick or keeps it in a range you choose. It is one small bash script for Apple silicon MacBooks, made for the macOS versions where older charge limiters stopped working.

$ batterycharging status
batterycharging 1.0.8
  Battery:       58%, on AC Power, not charging
  Charge limit:  58%
  Hold:          on, the limit follows the battery down, unless range is on (see Range for its limits)
  Range:         on, below 40% a hold charges back up to 60%
  'on' restores: 80% charge limit

Install

curl -fsSL https://raw.githubusercontent.com/anarchy89/batterycharging/main/setup.sh | sh

It needs an Apple silicon MacBook on macOS 27 or later, or macOS 26.7 or later, and an admin password. Update later with batterycharging --update.

On macOS 26.6 and earlier use actuallymentor/battery instead. It has more features and works well on those versions.

Use

batterycharging off          # stop charging: hold at the current level
batterycharging to 65        # charge up to 65%, then hold there
batterycharging range        # keep it in a range: below 40%, charge back up to 60%
batterycharging range 30 65  # the same with your own values
batterycharging on           # back to normal charging

batterycharging status       # what is set right now and what to run next
  • off holds the battery at its current level. The Mac runs on wall power and the battery never charges back up.
  • to N charges to the level you give, then holds there in the same way.
  • range adds a floor to a hold: when the battery falls below the low value it charges back up to the high value and holds again.
  • on stops the hold and restores the charge limit you had before, such as 80%.
A hold on its own never charges the battery back up, so left long enough it drains to 0%. Set a range, or run batterycharging on when it gets low.

Why it exists

Tools such as battery stop charging by writing the SMC key CHTE. The firmware that ships with macOS 27 and the macOS 26.7 update no longer has that key, so those writes fail. Apple's replacement interface only accepts callers with a private entitlement that third-party tools cannot get.

batterycharging drives macOS's own Manual Charge Limit instead, the feature behind System Settings, Battery, Charge Limit. System Settings offers 80% to 100%, but the setting underneath accepts any value from 1 to 100. The firmware then stops charging at that limit, including while the Mac sleeps.

What it does

  • Stops charging at any level, not only at 80% and above.
  • Follows the battery down, so it is never topped back up to a fixed limit over and over.
  • Charges to a level you choose and stops there.
  • Keeps the battery between a low and a high value if you set a range.
  • Shows what is set and what to run next with status.
  • Puts your original charge limit back with one command.
  • Updates itself with --update.
  • Is one readable bash script with nothing else to install.
